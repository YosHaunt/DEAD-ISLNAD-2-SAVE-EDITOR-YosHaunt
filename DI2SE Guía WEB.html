--- VARIABLES PRINCIPALES ---

  • <RUTA_GUARDADO> : Ruta a tu archivo de guardado.
    • Steam: "%LocalAppData%\DeadIslandSteam\Saved\SaveGames\DeadIsland2SaveGame.sav"
    • Epic: "%LocalAppData%\DeadIsland\Saved\SaveGames\DeadIsland2SaveGame.sav"
  • <PROFILE_ID> : ID alfanumérico del personaje.
  • <ENTRY_ID> : ID único del objeto (obtenido con el comando 'ls').
  • <NOMBRE_OBJETO> : Nombre del objeto (ej. DA_MeleeWeaponArchetype_Katana).
  • <NOMBRE_MEJORA> : Nombre de la mejora (ej. DA_ItemUpgradeData_IncreaseReloadSpeed).
  • <rarity> : common | uncommon | rare | superior | legendary
  • <nivel> : Nivel del 1 al 30.
  • <cantidad> : Cantidad de objetos/dinero.
  • <durabilidad> : Valor numérico (ej. 100.0 o 9999.0).
  • <seed> : Semilla numérica para stats (ej. 1234).

1. DESEMPAQUETAR / EMPAQUETAR ARCHIVOS

Desempaquetar guardar:
di2save file unpack --file <RUTA_GUARDADO> --output-file SaveGame.unpacked
Reempaquetar guardar:
di2save file pack --file SaveGame.unpacked --output-file SaveGame.repacked

2. PERFILES Y PERSONAJES

Listar personajes / perfiles:
di2save player profile ls --file <RUTA_GUARDADO>

3. INVENTARIO DEL JUGADOR

Listar inventario:
di2save player inventory ls --file <RUTA_GUARDADO> --profile <PROFILE_ID>
Ver detalle de un objeto:
di2save player inventory show <ENTRY_ID> --file <RUTA_GUARDADO> --profile <PROFILE_ID>
Añadir objeto básico:
di2save player inventory add --file <RUTA_GUARDADO> --profile <PROFILE_ID> --name <NOMBRE_OBJETO> --rarity <rarity> --level <nivel> --count <cantidad>
Añadir objeto avanzado (no registrado):
di2save player inventory add --file <RUTA_GUARDADO> --profile <PROFILE_ID> --archetype <ARCHETYPE> --type MeleeWeaponArchetype --instanced true --count <cantidad>
Duplicar / Clonar objeto:
di2save player inventory clone <ENTRY_ID> --file <RUTA_GUARDADO> --profile <PROFILE_ID>
Editar objeto existente:
di2save player inventory edit --file <RUTA_GUARDADO> --profile <PROFILE_ID> --item <ENTRY_ID> --level <nivel> --rarity <rarity> --durability <durabilidad> --count <cantidad> --seed <seed>
Eliminar objeto:
di2save player inventory rm --file <RUTA_GUARDADO> --profile <PROFILE_ID> <ENTRY_ID>

4. MEJORAS Y MODS DE ARMAS

Añadir mejora por nombre corto:
di2save player inventory upgrade add --file <RUTA_GUARDADO> --profile <PROFILE_ID> --item <ENTRY_ID> --name <NOMBRE_MEJORA>
Añadir mejora por Archetype:
di2save player inventory upgrade add --file <RUTA_GUARDADO> --profile <PROFILE_ID> --item <ENTRY_ID> --archetype <ARCHETYPE>
Eliminar mejora de un arma:
di2save player inventory upgrade rm --file <RUTA_GUARDADO> --profile <PROFILE_ID> --item <ENTRY_ID> --name <NOMBRE_MEJORA>

5. BAÚL / ALMACÉN (STASH)

(Nota: Para NG+ usa --ng+=1; para partida normal usa --ng+=0)

Listar baúl:
di2save stash ls --file <RUTA_GUARDADO> --ng+=0
Ver detalle de ítem en baúl:
di2save stash show <ENTRY_ID> --file <RUTA_GUARDADO> --ng+=0
Añadir ítem al baúl:
di2save stash add --file <RUTA_GUARDADO> --name <NOMBRE_OBJETO> --rarity <rarity> --level <nivel> --count <cantidad> --ng+=0
Clonar ítem del baúl:
di2save stash clone <ENTRY_ID> --file <RUTA_GUARDADO> --ng+=0
Editar ítem del baúl:
di2save stash edit --file <RUTA_GUARDADO> --item <ENTRY_ID> --level <nivel> --rarity <rarity> --durability <durabilidad> --count <cantidad> --ng+=0
Eliminar ítem del baúl:
di2save stash rm --file <RUTA_GUARDADO> <ENTRY_ID> --ng+=0

6. EDICIONES RÁPIDAS (QUICK EDITS)

Maximizar Nivel / XP:
di2save quick apply max-xp --file <RUTA_GUARDADO>
Desbloquear todos los Planos (Blueprints):
di2save quick apply unlock-blueprints --file <RUTA_GUARDADO>
Desbloquear todos los Arrojadizos (Curveballs):
di2save quick apply unlock-curveballs --file <RUTA_GUARDADO>

7. AYUDA Y BÚSQUEDA DE NOMBRES DE OBJETOS

Listar objetos conocidos:
di2save help inventory items
Listar objetos incluyendo DLCs / IA / Internos:
di2save help inventory items --include-dlc --include-ai --include-internal
Listar únicamente ítems DLC / IA / Internos:
di2save help inventory items --only-dlc
di2save help inventory items --only-ai
di2save help inventory items --only-internal
Listar mejoras disponibles:
di2save help inventory upgrades
Listar ediciones rápidas:
di2save help quick
